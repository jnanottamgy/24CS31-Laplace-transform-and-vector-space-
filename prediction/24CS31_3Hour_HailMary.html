4Prove the tn-multiplication rule 07 marks · Unit I · Q1c or Q2b — 4/4 papers, word for word
If L{f(t)} = F(s), prove that  L{tnf(t)} = (−1)n dndsn{F(s)},  n a positive integer.
Script — learn these four lines. F(s) = ∫0∞e−stf(t) dt. Differentiate under the integral sign: F′(s) = ∫0∞(−t)e−stf(t)dt = −L{t f(t)}. Repeat n times → each pass drops one factor of (−t). Finish by induction on n: assume true for n, differentiate once more, get n+1. State the base case n=1.
