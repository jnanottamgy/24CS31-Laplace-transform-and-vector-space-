Q1cProve the tn rule  — 7 marks
Prove  L{tnf(t)} = (−1)n dndsn{F(s)}
Learn this as a script. It has been asked word-for-word in all four papers.
  • Start: F(s) = ∫0∞e−stf(t) dt
  • Differentiate under the integral sign → F′(s) = −L{t f(t)}
  • Each further differentiation drops another (−t)
  • Finish with induction on n. State the base case n = 1.

Q3cPiecewise function + Laplace transform  — 7 marks
Express  f(t) =
t2,0 < t < 2
4t,2 < t < 4
8,t > 4
  using the Heaviside function, then find its Laplace transform.
Three steps.
  • Stack the jumps:  f = t2 + (4t−t2)u(t−2) + (8−4t)u(t−4)
  • Rewrite each bracket in terms of (t−a) → you get 4 − τ2  and  −8 − 4τ
  • Apply second shifting:  L{g(t−a)u(t−a)} = e−asG(s)
Answer:  2/s3 + e−2s(4/s − 2/s3) + e−4s(−8/s − 4/s2)
Q3dSolve an ODE by Laplace transforms  — 7 marks
It will be one of these three:
•  dxdt − 2y = cos 2t  and  dydt + 2x = sin 2t,  x(0)=1, y(0)=0
•  y″ + 4y′ + 3y = e−t
•  A circuit:  Ldidt + Ri = Ee−at
Same method for all three.
  • Transform every term. Use L{y′} = sY − y(0)  and  L{y″} = s2Y − sy(0) − y′(0)
  • Put the initial conditions in at this step. Then it is just algebra.
  • One equation → solve for Y(s), invert by partial fractions.
  • Two equations → solve them like simultaneous equations in X(s) and Y(s), then invert each.

Q5cRotation proof  — 7 marks
Show that T(x) = Ax rotates x through an angle θ about the origin, where
A =
cosθ−sinθ
sinθcosθ
Bookwork. Twelve minutes. No calculus.
  • Write x in polar form:  x = (r cos φ,  r sin φ)
  • Multiply out Ax
  • Use the compound-angle formulae → you get (r cos(θ+φ),  r sin(θ+φ))
  • Same length r, angle increased by θ. That is a rotation. Done.
