## Course at a glance

- **Credits:** 2:1:0 (3 total) · **Contact hours:** 30L + 30T + 30S
- **Pre-requisites:** Calculus and Basics of Linear Algebra
- **Assessment:** CIE 50 (tests 30 + quiz 10 + assignment 10) · SEE 100

**Units**

1. Laplace Transforms
2. Application of Laplace Transforms
3. Vector Space and Linear Transformation
4. Orthogonal Projections
5. Applications of Eigenvalue Decomposition

See [`SYLLABUS.md`](SYLLABUS.md) for the full breakdown.
